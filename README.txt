UNIVERSAL VIDEO → MP4

HOW TO START
1. Extract this ZIP to a normal folder.
2. Double-click: Universal Video to MP4.vbs
3. On the first launch only, the app downloads its FFmpeg conversion engine automatically.
4. Add or drag videos, choose a resolution, click Convert to MP4.

INPUT
MP4, MOV, MKV, AVI, WMV, WebM, M4V, MPEG/MPG, TS/MTS/M2TS, FLV, 3GP/3G2,
VOB, OGV, ASF, RM/RMVB, MXF and many other formats supported by FFmpeg.

OUTPUT
Standard .mp4 using H.264 video + AAC audio.

RESOLUTION OPTIONS
Original, 2160p/4K max, 1440p max, 1080p max, 720p max, 480p max.
The app only downsizes when needed; it does not intentionally upscale smaller videos.

NOTES
- Windows desktop app. No browser is used.
- First launch needs internet so FFmpeg can be downloaded. After that, conversion is local/offline.
- Converted files default to the same folder as the source videos.
