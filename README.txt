# Installation Guide

## 1. Download

Download:

`Universal_Video_to_MP4_Windows.zip`

## 2. Extract

Right-click the ZIP file and select:

`Extract All...`

Open the extracted folder.

## 3. Start the App

Double-click:

`Universal Video to MP4.vbs`

On the first launch, the app will:

- Create the Windows executable
- Download the required FFmpeg conversion engine
- Prepare everything needed for video conversion

Internet access is required for the first launch.

After setup is complete, the converter runs locally on your computer.

## 4. Convert a Video

1. Open the application.
2. Add one or more video files.
3. Select the output resolution.
4. Choose the output folder if required.
5. Click **Convert**.
6. The converted files will be saved as standard `.mp4` files.

## Supported Input Formats

Common formats include:

- MOV
- MP4
- MKV
- AVI
- WMV
- WebM
- M4V
- MPEG
- MPG
- TS
- MTS
- M2TS
- FLV
- 3GP
- VOB
- OGV
- ASF
- MXF

Other FFmpeg-supported video formats may also work.

## Output Format

All videos are converted to:

`MP4 (H.264 video + AAC audio)`

This format is compatible with most:

- Windows computers
- Android devices
- iPhones and iPads
- TVs
- Browsers
- Video editors
- Social media platforms

## Resolution Options

- Original Resolution
- 2160p / 4K
- 1440p
- 1080p
- 720p
- 480p

Selecting a lower resolution reduces the output file size.

## Batch Conversion

Multiple videos can be added at the same time.

The application converts them one after another and saves each result as an MP4 file.

## Drag and Drop

Supported video files can also be dragged directly into the application window.

## Windows Security Warning

If Windows SmartScreen displays a warning:

1. Click **More info**
2. Click **Run anyway**

This can happen because the application is not digitally signed.

## Requirements

- Windows 10 or Windows 11
- Internet connection for first-time setup
- Enough free disk space for the converted videos
